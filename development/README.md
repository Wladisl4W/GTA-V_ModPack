# Разработка

Здесь находятся проекты загрузчика и CrashWatcher, общие тесты, скрипты сборки, реестр и локальные результаты. Игровые `.cs` находятся в `../scripts/ReloaderPlugins/Plugins`, а исходники Ped Importer и PedToProp — в `../scripts/ReloaderPlugins/Tools`. Содержимое папки `scripts` можно скопировать в `GTA V/scripts`.

Команды выполняются из корня репозитория: `modpack.cmd Check` проверяет код, `modpack.cmd Build` обновляет готовые DLL/EXE в `scripts`. `development/build/package-release.ps1` собирает и проверяет единый архив для установки.
