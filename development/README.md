# Разработка

Здесь находятся проекты загрузчика, CrashWatcher, Ped Importer, PedToProp, профильные тесты и технические README. Игровые `.cs` находятся в `../modules/ReloaderPlugins/Plugins`, чтобы папку `modules` можно было скопировать целиком в `GTA V/scripts`.

Команды выполняются из корня репозитория: `modpack.cmd Check` проверяет код, `modpack.cmd Build` обновляет готовые DLL/EXE в `modules`. `tools/package-release.ps1` собирает и проверяет единый архив для установки.
