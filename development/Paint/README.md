# Машины и покраска (Paint)

Клавиша I открывает покраску выбранной машины. Клавиша T открывает только пресеты массовых действий. Обмен моделей доступен через L → «Обмен моделей машин».

## Как запустить

Клавиши **I, T**: нажмите I для покраски машины под прицелом или T для меню пресетов. Для выбора машины или педа лучом откройте **Object Spooner** (F9) и наведите камеру на цель; маркер показывает обнаруженный объект.

## Что можно сделать

- «Покраска машины»: назначить основной и вторичный цвета, тип покрытия и радужный перелив выбранной машине.
- «Пресеты»: первый пункт «Дефолтный» задаёт параметры новых пресетов. Ниже расположена команда создания, затем сохранённые пресеты по алфавиту. Порядок записей в JSON при этом не меняется. Новые пресеты создаются копией дефолтного; существующие сохраняют свои настройки. В редакторе пресета доступны случайная покраска, номера, варианты текстур объектов, погода, облака, двери и пассажиры мотоциклов.
- В редакторе сначала идёт галочка действия, сразу под ней — его настройка: покраска, список моделей объектов для текстур, текст номера, модели дверей или пассажиров. Настройки доступны и при выключенной галочке, чтобы подготовить пресет заранее. Каждое изменение записывается автоматически; имя и номер — после подтверждения ввода. Кнопки сохранения нет. Если запись не удалась, игра показывает ошибку, а прежний файл сохраняется.
- В списке моделей текстур можно добавить объект наведением камеры в Object Spooner или убрать модель. Выбирается модель объекта, поэтому рандом применяется ко всем загруженным объектам этой модели. Пресеты без нового списка получают прежний набор моделей рамп и блоков; пустой сохранённый список остаётся пустым. Веса вариантов 1–15 и правило соседних объектов сохранены. Некоторые модели могут не поддерживать смену tint variation.
- «Случайная погода» и «Случайные облака» — две независимые галочки. Под каждой находится список встроенных вариантов GTA с отметками. При применении пресета из каждого включённого непустого списка выбирается один вариант с равным шансом. Старые пресеты получают полные списки, но обе галочки остаются выключенными. Если список пуст, действие пропускается с сообщением. Погода устанавливается до облаков; облака переходят к выбранному виду за 3 секунды. Следующие действия игры или других модов могут сменить погоду и облака.
- Наведение на строку облаков временно показывает этот вид, независимо от галочки; отметка меняется только нажатием Enter. При выходе временное облако снимается, а если предыдущий вид был задан этим плагином при применении пресета, он загружается снова. Предпросмотр не очищает остальные облака сцены. Игровой API не сообщает имя облаков, заданных Menyoo или другим модом, поэтому их точный возврат при одновременном управлении небом требует проверки в игре.
- Старый общий список пассажиров доступен в редакторе пресета через «Добавить из старого списка»; после переноса модели хранятся в самом пресете.
- «Обмен моделей» в меню L: выбрать две разные модели машин через прицел и поменять местами все загруженные экземпляры этих моделей. Сохраняются позиция, полный поворот и заморозка; индивидуальные номера, тюнинг и повреждения не переносятся. Занятые и прикреплённые машины пропускаются.

## Данные

Настройки, исключения, пресеты и список пассажиров лежат в `scripts/ReloaderPlugins/Plugins/Paint/Data/Settings`: `RainbowPaintSettings.json`, `RainbowPaintExceptions.json`, `RainbowPaintPresets.json`, `RainbowPaintPassengerModels.json`. Исторические имена файлов сохранены. Сделанные изменения транспорта и объектов не являются отдельным сохранением мода; при необходимости сохраняйте мир через Menyoo.

## Зависимости и ограничения

Нужны Reloader, ScriptHookVDotNet3, LemonUI; выбор лучом требует Object Spooner. Массовые действия затрагивают загруженные сущности, включая трафик поблизости. Перед сохранением сцены проверьте расположение машин после обмена и результат загрузки карты Menyoo; успешная сборка не подтверждает сохранение мира.

## Состояния

Для обмена: `выбор модели A → выбор модели B → подготовка замен → обмен`. Пока группа готовится, исходные машины сохраняются; отмена меню или F5 прекращает незавершённую подготовку. Списки моделей и пресеты сохраняются отдельно от живых объектов мира.

## Обновление и откат

`modpack.cmd Update Paint` доставляет исходники. Сохраните четыре JSON перед откатом; не переименовывайте их вручную.
