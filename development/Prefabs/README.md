# Заготовки (Prefabs)

Мод ставит стенку из мячей и случайно изогнутую горку из `prop_skate_halfpipe` в Object Spooner.

## Как запустить

Откройте **Object Spooner** (F9), затем нажмите **;**. В меню выберите стенку или горку. Режимы размещения работают только при активной скриптовой камере Spooner.

## Что можно сделать

- Для стенки наведите прицел на место: до подтверждения показываются маркеры. **Enter** или **;** размещает стенку 10 × 5, **Backspace** отменяет предпросмотр.
- Для горки наведите на верхнюю точку. Синим отмечается начало, красным конец, а точки показывают рассчитанную траекторию; **Enter** или **;** подтверждает размещение. При новом наведении траектория пересчитывается.
- Секции горки замораживаются после создания. Первая техническая секция сразу удаляется; при касании игроком последующих секций пройденная часть удаляется через пять секунд. После шести разных касаний оставшиеся секции удаляются через минуту.

## Данные

Собственных настроек и файлов сохранения нет. Созданные объекты живут в игровом мире; сохранение через Menyoo выполняется отдельно. После F5 отслеживание автоудаления ранее созданной горки не восстанавливается.

## Зависимости и ограничения

Нужны Reloader, ScriptHookVDotNet3, LemonUI, Object Spooner и доступная модель `prop_skate_halfpipe`. Предпросмотр точками не гарантирует идеальную физику на любой местности; стыки и движение проверяются в игре.

## Исходники и проверка

Код: [PrefabsPlugin.cs](../../modules/ReloaderPlugins/Plugins/Prefabs/Code/PrefabsPlugin.cs). `modpack.cmd Check` проверяет компиляцию; форму горки и автоудаление — в GTA.

## Обновление и откат

`modpack.cmd Update Prefabs` доставляет исходник. Для отката восстановите проверенную копию. Созданные объекты не являются данными плагина и не мигрируют.
