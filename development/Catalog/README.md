# Каталог модов (Catalog)

Меню F5 показывает игровые модули пакета, их назначение и клавиши. Пункты служат справочником: выбирать их для запуска модов не нужно.

## Как запустить

Нажмите **F5** в игре. Повторное нажатие закрывает список.

## Что можно сделать

- Найти нужное игровое меню по его названию и посмотреть клавишу справа.

## Данные

У каталога нет постоянных настроек. Названия, клавиши, описания и порядок игровых меню заданы в [ModuleMenus.cs](../../modules/ReloaderPlugins/Plugins/_System/Shared/Code/ModuleMenus.cs); [CatalogPlugin.cs](../../modules/ReloaderPlugins/Plugins/Catalog/Code/CatalogPlugin.cs) строит список по этому реестру. Технические ID и владельцы файлов перечислены в [реестре сборки](../../catalog/modules.json). Меню F5 само не включает и не выключает другие моды.

## Зависимости и ограничения

Использует Reloader, ScriptHookVDotNet3 и LemonUI. Список отражает модули пакета, а не автоматически обнаруженные сторонние скрипты GTA.

## Проверка и обновление

`modpack.cmd Check` проверяет компиляцию. После изменения списка сверяйте названия и клавиши с реальными меню в GTA. Исходник доставляется командой `modpack.cmd Update Catalog`; прежнюю версию можно вернуть из проверенной резервной копии.
