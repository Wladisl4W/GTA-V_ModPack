# Импорт педов (PedImporter)

Отдельная программа ModPack для массового добавления педов в избранное Menyoo.
Готовая программа: `dist/Tools/PedImporter/PedImporter.exe`.

## Как запустить

Запустите программу **при закрытой GTA**. По умолчанию открыт простой режим «Избранное Menyoo»; режим «Полный импорт» выбирается отдельно.

## Избранное Menyoo

1. Заранее перенесите файлы моделей через OpenIV и зарегистрируйте педов в AddonPeds.
   Выполните Rebuild. Ped Importer в этом режиме не делает эти шаги.
2. Закройте GTA, запустите Ped Importer и оставьте выбранным режим «Избранное Menyoo».
3. Укажите общую папку моделей и папку GTA V. Нажмите «Проверить модели».
   Модели группируются по имени файла; требуются `.ydd`, `.ytd`, `.yft`, `.ymt`.
   Дополнительные файлы допустимы. Одноимённая папка означает Streamed=true.
4. Отметьте нужных педов. Столбец «Избранное» показывает, кто уже есть в Menyoo.
   Нажмите «Добавить выбранных» и проверьте количество новых и пропущенных записей.
5. Запустите GTA и проверьте новых педов в избранном Menyoo. Для первого раза
   рекомендуется добавить одного установленного педа, затем всю пачку.

В режиме «Избранное Menyoo» программа меняет только `menyooStuff/FavouritePeds.xml`. Существующие записи
сохраняются, дубликаты по хешу пропускаются. Перед заменой файла создаётся
резервная копия `.bak` рядом с ним. При повреждённом XML или ошибке записи
исходный файл не перезаписывается. Добавление в избранное не доказывает, что
модель установлена правильно; это проверяется в игре.

## Полный импорт

Режим «Полный импорт» содержит прежние команды для AddonPeds Editor v3.0:
«Проверить редактор», «Зарегистрировать и Rebuild», «Остановить». Он управляет
редактором через Windows UI Automation и требует проверки на реальном окне вашей
версии. При неизвестном диалоге или тайм-ауте избранное не обновляется.
«Остановить» не отменяет уже начатый Rebuild; перед повторной попыткой проверьте
список в редакторе. Настройки и журнал находятся в
`%LOCALAPPDATA%/ModPack/PedImporter`.

## Данные, зависимости и ограничения

Программа запрашивает права администратора, поскольку работает с файлами GTA в
`Program Files` и в полном режиме управляет AddonPeds Editor. Для простого режима нужны уже установленные модели и выполненный Rebuild; OpenIV и AddonPeds остаются внешними инструментами. Настройки и журнал программы лежат в `%LOCALAPPDATA%/ModPack/PedImporter`.

## Исходники и проверка

Исходники: [src](src), запись избранного: [Catalog.cs](src/Catalog.cs). На копии XML проверьте одну модель, повторный запуск без дублей и резервную копию; результат в настоящем Menyoo проверьте после запуска GTA.

## Обновление и откат

Сборка и доставка текущей версии в `dist/Tools/PedImporter`:
`powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/build-ped-importer.ps1`.
Закройте программу перед обновлением; если `.exe` занят, скрипт сохранит прежнюю
поставку и сообщит об этом. Старые папки `Update-*` больше не создаются.
