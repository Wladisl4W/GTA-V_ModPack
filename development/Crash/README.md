# Отчёты о сбоях (Crash)

Фоновый модуль собирает сведения о текущем запуске GTA и запускает наблюдатель CrashWatcher для отчёта после завершения процесса.

## Как запустить

Отдельной клавиши и меню нет. При загрузке Reloader модуль автоматически создаёт контекст сессии и запускает наблюдатель. Для настройки системного захвата дампов используются отдельные команды из [руководства разработчика](../../docs/DEVELOPMENT_RU.md).

## Что можно сделать

- Найти журнал сессии, heartbeat и отчёт наблюдателя после сбоя или необычного завершения.
- Сопоставить отчёт с журналами известных модулей, событиями Windows и дампами текущей сессии, если они доступны.

## Данные

Во время работы в `scripts/ReloaderPlugins/Plugins/Crash/Data` создаются `CrashSession-<pid>.log`, `CrashHeartbeat-<pid>.txt`, `CrashMonitor.log`, runtime-копия наблюдателя и папки отчётов/дампов. Поставляемый `CrashWatcher.exe` находится в `Plugins/Crash/Tools`. Загрузчик и модули хранят собственные журналы в своих папках.

## Зависимости и ограничения

Нужны Reloader, ScriptHookVDotNet3 и поставляемый CrashWatcher. Системный захват дампов может требовать отдельной установки с правами администратора. Не каждый сбой создаёт дамп, а отчёт не всегда определяет исходный виновный мод. Menyoo и AddonPeds не меняются.

## Состояния

`запуск плагина → контекст и heartbeat → наблюдение процесса → отчёт или очистка штатной сессии`. Наблюдатель работает отдельным процессом, поэтому может записать итог после закрытия GTA.

## Исходники и проверка

Плагин: [CrashPlugin.cs](../../modules/ReloaderPlugins/Plugins/_System/Diagnostics/Code/Crash/CrashPlugin.cs), наблюдатель: [Program.cs](src/Program.cs). Проверка: `modpack.cmd Check` и профильные тесты в `development/Crash/tests`. Реальный дамп подтверждается только фактическим сбоем и проверкой файлов сессии.

## Обновление и откат

Обычная доставка выполняется `modpack.cmd Update` вместе с инструментами Crash. Перед изменением системных настроек захвата сохраните их резервную копию; откат исходников сам по себе настройки Windows не возвращает.
