# Анимации педов (Animations)

В Object Spooner мод позволяет выбрать нескольких педов прицелом и назначить им одно действие или клип анимации.

## Как запустить

Откройте **Object Spooner** (F9), наведите прицел на живого педа и нажмите **Y**. В меню «Выбрать педа» добавьте цель в список. **Backspace** возвращает на предыдущий экран, а из главного меню закрывает его.

## Что можно сделать

- Выбрать нескольких педов; игрок, мёртвые педы и повторные попадания в список не добавляются. Цель и выбранные педы отмечаются маркерами, пока меню открыто.
- Выбрать готовое действие, клип из полного каталога с поиском или анимацию из избранного Menyoo. Анимация запускается для всех выбранных; новый пед получает текущую.
- Убрать одного педа, остановить назначенные модом анимации с сохранением списка или очистить весь список.

## Данные

Плагин читает `menyooStuff/PedAnimList.txt` и `menyooStuff/FavouriteAnims.xml`. Он не изменяет эти файлы. Избранное обновляется при изменении XML; недоступность одного файла не отключает остальные разделы. Выбор педов не сохраняется между игровыми сессиями.

## Зависимости и ограничения

Нужны Reloader, ScriptHookVDotNet3, LemonUI и Menyoo Object Spooner. При активной старой `DanceMode.dll` мод предупреждает о конфликте клавиши Y. Анимации назначаются через игровой API и не попадают автоматически в данные Save World Menyoo.

## Состояния

`выбор педов → запрос словаря → воспроизведение`: словарь загружается асинхронно с тайм-аутом 5 секунд; пока новая анимация не готова, старая продолжает работать. После выхода из Spooner список и проигрывание остаются, меню закрывается. F5 останавливает свои клипы и сбрасывает список.

## Исходники и проверка

Код: [AnimationsPlugin.cs](src/Code/AnimationsPlugin.cs), каталог: [AnimationCatalog.cs](src/Code/AnimationCatalog.cs). Проверка: `modpack.cmd Check` и `powershell.exe -NoProfile -ExecutionPolicy Bypass -File modules/Animations/tests/test-ped-animations.ps1`. Выбор лучом и видимость клипов проверяйте в GTA.

## Обновление и откат

`modpack.cmd Update Animations` доставляет исходники. Menyoo-файлы и старые сохранения DanceMode при этом не меняются.
