# Заготовки

Клавиша: **;**. Создание конструкций в Object Spooner.

Через **T → Задать префабы → Поставить новый** тот же предпросмотр запоминает место заготовки без появления объектов. Они создаются только в зоне загрузки после применения пресета.

Исходники Reloader компилирует из папки Code. Меню **O → Стриминг префабов** запоминает поставленные горки и стенки мячиков. Кнопка «Включить» захватывает конструкции в радиусе сканирования, в том числе объекты, оставшиеся после F5. После удаления или выгрузки они восстанавливаются при повторном приближении. Горка возвращается с той же формой, без новой генерации. У мячиков, оставшихся после F5, исходной точкой считается их положение в момент включения стриминга. Отключение или F5 удаляет объекты, которыми управляет стриминг. Настройки радиусов и лимита сохраняются в `Data/Settings/PrefabStreaming.json`; снимки конструкций после F5 и между запусками не сохраняются.

Проверка сборки: `modpack.cmd Check` в каталоге разработки. Работу меню и игровых эффектов проверяйте в GTA.
