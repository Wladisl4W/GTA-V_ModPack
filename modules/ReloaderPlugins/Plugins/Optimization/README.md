# Оптимизация

Клавиша: **O**. Загрузка, очистка и управление персонажами.

Исходники Reloader компилирует из папки Code. Данные каждого подраздела: Data/Streamer, Data/Cleanup, Data/PedControl.

Проверка сборки: `modpack.cmd Check` в каталоге разработки. Работу меню и игровых эффектов проверяйте в GTA.
