# Удаление упавших педов

Вход: O → Оптимизация → Удаление упавших педов. Главная галочка включает удаление; радиус и частота находятся в «Настройках»; данные: ../../Data/Cleanup.

Это самостоятельный раздел кода внутри меню Optimization. Исходники компилируются загрузчиком Reloader вместе с остальными плагинами.
