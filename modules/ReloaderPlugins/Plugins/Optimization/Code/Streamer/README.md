# Стриминг педов

Вход: O → Оптимизация → Стриминг педов. Зелёная кнопка включает поток с захватом педов по текущим настройкам, затем становится красной кнопкой выключения. Выключение удаляет созданных им педов. Радиусы и лимит находятся в «Настройках»; данные: ../../Data/Streamer.

Это самостоятельный раздел кода внутри меню Optimization. Исходники компилируются загрузчиком Reloader вместе с остальными плагинами.
