# Разное

Клавиша: **L**. Оружие, физика, животные, следящая камера и обмен моделей машин.

Исходники Reloader компилирует из папки Code. Данные подразделов: Data/Wildlife, Data/FollowCamera и другие по мере необходимости.

Проверка сборки: `modpack.cmd Check` в каталоге разработки. Работу меню и игровых эффектов проверяйте в GTA.
