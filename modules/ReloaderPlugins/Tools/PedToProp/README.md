# PedToProp

Запускайте `PedToProp.exe` вручную из этой папки. Выберите ровно четыре файла одного не-streamed педа (`.ydd`, `.ytd`, `.yft`, `.ymt`) и папку результата. Blender с Sollumz должен быть установлен и настроен через `setup.ps1`.

Программа не устанавливает результат в GTA. Проверьте созданный `.ydr` в просмотрщике перед размещением в игре.
