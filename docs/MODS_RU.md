# Моды и клавиши

Это короткий указатель. Подробные действия, данные и ограничения описаны в README каждого модуля. Клавиши сверены с [реестром модулей](../development/registry/modules.json).

| Мод | Клавиша | Для чего | Инструкция |
| --- | --- | --- | --- |
| Каталог модов | F5 | Посмотреть состав пакета и клавиши | [Catalog](modules/Catalog.md) |
| Камера | K | Записать, сохранить и смешать пути камеры | [Camera](modules/Camera.md) |
| Замедление | Mouse4 | Замедлить момент и управлять камерой удержанием | [SlowMo](modules/SlowMo.md) |
| Машины и покраска | I — выбранная машина; T — пресеты; L — обмен моделей | Личная покраска, пресеты массовых действий и обмен моделей | [Paint](modules/Paint.md) |
| Анимации педов | Y | Назначить клип нескольким педам в Object Spooner | [Animations](modules/Animations.md) |
| Меню «Разное» и «Оптимизация» | L — разное; O — оптимизация | Оружие, физика, животные, следование камеры и обмен моделей; загрузка и очистка педов, управление NPC | [Hub](modules/Hub.md) |
| Оружие и физика | L → Оружие и физика | Оружие и скользкое падение | [Weapons](modules/Weapons.md) |
| Акула и крокодил | L → Животные; Mouse5 для вызова крокодила | Катание, атака акулы и вызов крокодила | [Wildlife](modules/Wildlife.md) |
| Стриминг педов | O → Стриминг педов | Включение потока и настройки загрузки | [Streamer](modules/Streamer.md) |
| Удаление упавших педов | O → Удаление упавших педов | Галочка удаления и настройки сканирования | [Cleanup](modules/Cleanup.md) |
| Заморозка/Разморозка | O → Заморозка/Разморозка | Мгновенные команды для загруженных NPC | [PedControl](modules/PedControl.md) |
| Заготовки | ; | Стенка из мячей и горка в Object Spooner | [Prefabs](modules/Prefabs.md) |
| Разработка | Ctrl+F10 | Панель состояний и диагностика | [Dev](modules/Dev.md) |
| Отчёты о сбоях | Без клавиши | Фоновый наблюдатель GTA и отчёты | [Crash](../development/Crash/README.md) |

## Отдельные программы

| Программа | Для чего | Инструкция |
| --- | --- | --- |
| Импорт педов | Массовое добавление установленных педов в избранное Menyoo; отдельный режим полного импорта | [PedImporter](../scripts/ReloaderPlugins/Tools/PedImporter/Files/DEVELOPMENT.md) |
| Конвертер педа в статичный проп | Конвертация четырёх файлов педа в статичный проп | [PedToProp](../scripts/ReloaderPlugins/Tools/PedToProp/Files/DEVELOPMENT.md) |

Menyoo и AddonPeds остаются внешними инструментами. Если мод зависит от Object Spooner, модели животного или файлов Menyoo, это указано в его инструкции. Для поиска по исходникам запустите `modpack.cmd Map` и откройте локальную карту проекта.
