# ModPack 3.0.0 — единая структура проекта

Исходники игровых модов и готовые файлы теперь находятся вместе в `scripts/ReloaderPlugins/Plugins`. Исходники Ped Importer и PedToProp тоже перенесены в `scripts/ReloaderPlugins/Tools`. Папка `development` содержит загрузчик, CrashWatcher, сборку, общие тесты и локальные рабочие материалы. Документация модулей находится в `docs/modules`.

У каждого инструмента в `Tools` на верхнем уровне только файл запуска `.cmd` и папка `Files`. Внутри `Files` находятся `Runtime`, `Source`, `Tests` и инструкции. Промежуточные файлы сборки в релиз не входят.

## Обновление с 2.2.0

1. Закройте GTA и обе программы. Сохраните копию `GTA V/scripts`, особенно папок `Data` и сохранённых пролёток камеры.
2. Распакуйте содержимое `ModPack-3.0.0.zip` в `GTA V/scripts` с заменой файлов. Папки `Data` не удаляйте.
3. После копирования удалите только прежние файлы верхнего уровня инструментов: `Tools/PedImporter/PedImporter.exe`, `PedImporter.exe.config`, `README.md`, а также `Tools/PedToProp/PedToProp.exe`, `convert_blender.py`, `setup.ps1`, `README.md`. Новые копии находятся в `Files/Runtime`, инструкции — в `Files`.
4. Запускайте программы через `Tools/PedImporter/PedImporter.cmd` и `Tools/PedToProp/PedToProp.cmd`. Проверьте F5 и свежий журнал Reloader после запуска игры.

Локальные WAV из стороннего Maneater не включены в Git и архив, поскольку разрешение на их распространение не подтверждено. Акула работает без этих звуков; файлы, уже установленные пользователем в `Plugins/Misc/Assets/Wildlife/Sounds`, при обновлении не удаляются. Оригинальный Maneater и его ресурсы распространяются автором отдельно.

Menyoo, AddonPeds, игровые архивы GTA и пользовательские данные в релиз не входят. Изменения проверены компиляцией, профильными тестами и распаковкой ZIP; визуальная проверка игровых режимов для этого выпуска отдельно не выполнялась.
