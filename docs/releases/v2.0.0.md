# ModPack 2.0.0 — большая перестройка проекта

Моды распределены по папкам `modules/<ID>` с отдельными README, кодом и тестами. В игре плагины теперь лежат в `scripts/ReloaderPlugins/Plugins/<ID>/Code`, а настройки и журналы — в `Plugins/<ID>/Data`. Заголовки меню и список F5 приведены к понятным русским названиям. Игровые действия и клавиши сохранены.

## Как обновиться с 1.6 и более старой плоской структуры

1. Скачайте **`ModPack-Install-2.0.0.zip`** и распакуйте его в отдельную временную папку, **не в GTA**. Закройте игру.
2. Запустите из распакованной папки:

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\Install-ModPack.ps1" -GameDirectory "C:\Program Files (x86)\Steam\steamapps\common\Grand Theft Auto V"
   ```

3. Установщик сверит хеши файлов, сохранит заменяемые файлы в `%LOCALAPPDATA%\ModPack\UpgradeBackups`, удалит только известные старые файлы ModPack из плоской папки `Plugins` и поставит новый `Reloader.dll` с плагинами. Если в корне `Plugins` есть неизвестный `.cs`, установка остановится до изменений: разберите этот файл вручную и повторите команду. Настройки, сохранённые пути камеры, Menyoo и AddonPeds установщик не меняет. При первом запуске плагины сами перенесут прежние настройки в папки владельцев; резервные и конфликтующие варианты сохраняются.
4. Запустите GTA. В `scripts/ReloaderPlugins/Plugins/Loader/Data/Logs/Reloader.log` проверьте свежие `Loaded 13 plugin(s)` и `Reload OK`. Откройте F5 и нужные меню.

Повторный запуск установщика допустим. Для отката закройте GTA и верните сохранённые копии из указанной установщиком папки; перед восстановлением отдельно скопируйте текущие настройки. Старый плоский набор `.cs` и новый набор `<ID>/Code` нельзя оставлять активными одновременно.

## Остальные архивы

`ModPack-Plugins-2.0.0.zip` и `Reloader-2.0.0.zip` предназначены для ручной установки. При переходе со старой версии **не распаковывайте только архив плагинов поверх прежних файлов**: старые `.cs` останутся в корне и могут конфликтовать. `PedImporter-2.0.0.zip` и `PedToProp-2.0.0.zip` — отдельные программы, устанавливаются только при необходимости.

Модели `epic_mc`, изображения, Menyoo, AddonPeds и пользовательские игровые данные в релиз не входят. Текущая структура и подробности восстановления: [инструкция установки](../INSTALL_RU.md).
