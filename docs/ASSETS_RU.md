# Ресурсы и внешние зависимости

Этот реестр относится к локальным файлам `development/assets/models`. Они исключены из Git до подтверждения прав на распространение. Их владелец в проекте — **медиаресурсы `epic_mc`**, а не игровой плагин. Архивы хранятся для работы над моделью и отката; команда обновления плагинов их не устанавливает. Названия версий описывают историю файлов, но сами по себе не доказывают их игровое содержимое.

`development/assets/models/epic_mc/dlc.rpf` — **текущая рабочая копия**: SHA-256 совпадает с установленным `GTA V/mods/update/x64/dlcpacks/epic_mc/dlc.rpf` на момент проверки 21 ноября 2026 года. Для изображений и базовой модели в репозитории не найдено подтверждённых сведений об авторе, первоначальном источнике и лицензии. Поэтому статус разрешения на распространение — **неизвестен**. Не добавлять эти файлы в публичный архив ModPack без отдельного подтверждения прав. Проверка реестра и исключения моделей из релизных ZIP: `python development/build/test-assets.py`.

## Внешние границы

- Menyoo и AddonPeds — сторонние программы. Их файлы, архивы и структура каталогов не являются ресурсами ModPack. Их не переносить и не переименовывать при перестройке проекта.
- Модуль Animations читает файлы Menyoo, Streamer использует его карты. Ped Importer меняет избранное Menyoo или управляет AddonPeds Editor только по отдельной явной команде пользователя.
- GTA, Script Hook V, ScriptHookVDotNet3, LemonUI, OpenIV, Blender и Sollumz — внешние зависимости. `Newtonsoft.Json.dll` в папке плагинов — поставляемая общая зависимость Core; для PedToProp используется отдельная копия Sollumz в локальных данных программы.

Текущие правила упаковки и восстановления: [данные и доставка](DATA_AND_DELIVERY_RU.md).
