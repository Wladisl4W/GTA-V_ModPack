# Разработка GTA V ModPack

Карта модулей, единый реестр владельцев файлов и одинаковые README описаны в
`STRUCTURE_RU.md`. Жизненный цикл плагина — в [отдельной странице](PLUGIN_LIFECYCLE_RU.md), список модов и клавиш — в [индексе](MODS_RU.md). Команда `tools/build-project-map.ps1` создаёт локальную
поисковую карту без изменения GTA.

Правила кода и данных приведены в `docs/CONVENTIONS_RU.md`, шаблон README модуля — в `docs/MODULE_TEMPLATE_RU.md`.
Таблица фактических путей и порядок отката — в [реестре данных и доставки](DATA_AND_DELIVERY_RU.md).

## Папки данных модов

В `scripts/ReloaderPlugins/Plugins/<модуль>/Data` каждый игровой мод хранит
обычные настройки в `Settings`, журналы в `Logs`, сохранённые пути камеры в
`Camera/Data/Saves/Paths`. Общий `PluginErrors.log` находится в
`Plugins/Core/Data/Logs`. Ошибки переноса сохраняются там же в
`StorageMigration.log`. Данные сбоев находятся в `Plugins/Crash/Data`, а журналы
загрузчика — в `Plugins/Loader/Data/Logs`.

Обычные игровые данные перенесены пофайлово с проверкой SHA-256; проверенная
резервная копия находится в `.modpack-local/backups/data-20261119-234745`.
На других ПК плагин выполняет такой же перенос при первом обращении к файлу:
переносит резервные и повреждённые копии, сохраняет конфликт в `Legacy`, а при
ошибке продолжает использовать старый путь в текущей сессии. Форматы данных не меняются.

Новые плагины должны получать путь через `ModPack.Core.PluginStorage.FilePath`,
а не писать настройки и логи прямо в корень. Проверки переноса:
`powershell -NoProfile -ExecutionPolicy Bypass -File modules/Core/tests/test-storage.ps1` и
`powershell -NoProfile -ExecutionPolicy Bypass -File modules/Core/tests/test-regular-data.ps1`.

## Быстрый старт

Рабочие исходники модов находятся в `modules/<ID>/src/Code`. Для разработки нужны
Windows, Windows PowerShell 5.1, .NET SDK с поддержкой сборки net48, установленная
GTA V с Script Hook V, ScriptHookVDotNet3 и LemonUI.SHVDN3.

Создайте `modpack.local.json` по образцу `modpack.example.json` и укажите
`GameDirectory`. Локальный конфиг игнорируется Git. На текущем компьютере он уже
создан. Пути внутри репозитория определяются автоматически, рабочая папка терминала
не имеет значения.

Из корня репозитория:

```powershell
# Проверить ВСЕ плагины, ничего не копировать:
.\modpack.cmd Check

# Проверить и обновить dist и игру:
.\modpack.cmd

# Обновить при закрытой GTA, без ожидания игрового журнала:
.\modpack.cmd Update -Offline

# Обновить только один игровой модуль, если остальные уже синхронизированы:
.\modpack.cmd Update Camera

# То же с явным конфигом и временем ожидания:
.\modpack.cmd Update -Config "D:\configs\modpack.json" -TimeoutSeconds 45

# Проверить поведение загрузчика без GTA:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\modules\Loader\tests\test-reloader.ps1

# Проверить доставку в изолированной временной папке (после Release-сборки загрузчика):
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\test-update.ps1

# Системный захват тихого завершения GTA (однократное подтверждение UAC):
.\modpack.cmd SilentExit On
# Восстановить предыдущие настройки реестра:
.\modpack.cmd SilentExit Off
```

Код возврата 0 означает успешное завершение команды; ненулевой код означает ошибку.
Тест доставки использует временную копию структуры проекта и имитацию записи в
лог: он не запускает GTA и не изменяет установленные игровые файлы.
Если файлы уже совпадают, команда сообщает об этом и не заявляет о новой
перезагрузке. Если изменился только пакет dist, подтверждение игры не требуется.

## Однократное обновление загрузчика

Для команды Update нужен Reloader с файловой версией 2.0.0.0 или новее.
Это версия загрузчика, а не номер релиза ModPack. Старый загрузчик не поддерживает
блокировку пакетной доставки и отпечаток исходников в логе.

1. Закройте GTA V.
2. Соберите загрузчик:
   `dotnet build "modules\Loader\src\Reloader.csproj" -c Release`.
3. Замените `GTA V\scripts\Reloader.dll` файлом
   `modules\Loader\src\bin\Release\net48\Reloader.dll`.
4. Запустите игру. В `scripts\ReloaderPlugins\Plugins\Loader\Data\Logs\Reloader.log` после загрузки
   должна появиться строка `Reload OK: <отпечаток>`.

Обычная команда Update никогда не копирует DLL. Сборка загрузчика тоже не устанавливает
его в игру. Замена DLL при работающей игре не обновит уже загруженный код.

## Как работает проверка и доставка

Проверка и живой загрузчик используют один `PluginCompiler.cs`: CodeDOM из
.NET Framework, одинаковый набор системных ссылок и поиск библиотек в игровой
папке scripts и её ReloaderPlugins. Файлы `*.cs` берутся из корня Plugins и
из подпапок `<модуль>/Code`;
имена с начальным `_` исключены, кроме `_PluginInterface.cs`.
Все плагины компилируются вместе. Современный синтаксис, который понимает SDK,
может не поддерживаться живым CodeDOM: окончательная проверка модов — команда Check.

Update сначала компилирует исходники. При ошибке ничего не копируется.
Затем проверяет отсутствие лишних `.cs` в целевых папках: неизвестные или устаревшие
файлы нужно разобрать вручную. Исключение — старая плоская копия исходника,
который переносится в `<модуль>/Code`: после проверенной записи её удаляет Update.
Команда копирует только изменённые `.cs`, проверяет SHA-256 и общий отпечаток.
На время копирования создаётся `.deploy.lock`; новый Reloader откладывает перезагрузку.
При обычной ошибке копирования восстанавливаются предыдущие файлы.
Не редактируйте исходники параллельно с Update.

После доставки проверяются только новые байты лога и точное совпадение отпечатка.
Ожидание по умолчанию — 30 секунд. Тайм-аут означает: файлы доставлены, запуск
в игре не подтверждён. Он не откатывает уже скопированные файлы.
Запустите или снимите игру с паузы и проверьте лог. F5 открывает каталог модов;
ручную перезагрузку она больше не запускает. Изменение `.cs` загрузчик замечает сам.
Повторная команда без изменений не запускает повторную перезагрузку.

Если процесс доставки был принудительно завершён, может остаться `.deploy.lock`.
Убедитесь, что никакая доставка не выполняется, проверьте целостность файлов,
удалите этот конкретный файл из игровой Plugins и повторите Update.
Блокировка не имеет автоматического срока истечения.

## Безопасная перезагрузка

Старая версия продолжает работать, пока новая компилируется. Ошибка компиляции,
чтения исходников или получения типов не вызывает OnAbort старых плагинов.
Предупреждения сохраняются в `compile_errors.txt`, но допускают загрузку.
После чистой компиляции устаревший файл диагностики удаляется.

После успешной компиляции старые плагины получают OnAbort и запускаются новые.
Если конструктор или OnStart нового плагина бросает исключение, экземпляр очищается
через OnAbort и не получает OnTick. Лог содержит `Reload incomplete`.
Это не транзакционный откат игрового мира: ошибка запуска после остановки старой
версии не восстанавливает её. Исключения, которые сам плагин проглотил внутри
OnStart, загрузчик обнаружить не может.

OnTick и игровые native-вызовы остаются в игровом потоке. Компиляция синхронная
и может кратко приостановить кадры. Перезагрузка заменяет весь набор плагинов;
временное состояние и открытые меню могут сбрасываться.

## Как добавить или улучшить мод

### Ped Animations

Новый плагин `AnimationsPlugin.cs` открывает меню на **Y** в Object Spooner
(обычно **F9**). Добавьте педов пунктом «Выбрать педа», затем назначьте им действие
в разделе «Анимации». В «Выбранных педах» нажатие на запись убирает её из списка
и останавливает назначенную плагином анимацию. «Остановить анимации» сохраняет
выбор, «Очистить список» также убирает выбранных педов. Backspace возвращает на
предыдущий экран; Y закрывает весь интерфейс. При выходе из Spooner анимации
продолжаются, меню и маркеры скрываются. F5 останавливает собственные клипы;
педы не удаляются и не замораживаются. Выбор не сохраняется между сессиями.

«Готовые действия» содержит именованные пресеты обычного раздела анимаций
Menyoo, включая махание руками и поднятые руки. «Все анимации» читает
`menyooStuff\PedAnimList.txt`, показывает страницы по 50 записей и поиск по
словарю/клипу. Поиск принимает латинские символы, цифры, `_`, `@`, `^`, `-`,
точку и пробел; Enter применяет, Escape отменяет, Backspace удаляет символ.
«Избранное» читает `menyooStuff\FavouriteAnims.xml` при изменении файла.
Исходные файлы Menyoo не изменяются. Каталоги читаются в фоне, игровые вызовы
остаются на потоке Reloader. Названия в меню сокращены, полные идентификаторы
показаны в описании. Ошибки файлов не отключают готовые действия.

Все анимации зациклены. Словарь загружается поэтапно с тайм-аутом 5 секунд;
при неудаче прежняя анимация остаётся. Новый выбор заменяет ожидающую загрузку.
Проверка прерывания выполняется не чаще двух раз в секунду; при падении/ragdoll
восстановление откладывается. Не каждый клип GTA пригоден для каждой модели:
каталог содержит и служебные, предметные, животные и сценические анимации.
Плагин не создаёт дополнительные предметы для клипов и не запускает парные сцены.

Проверка Spooner — эвристика по внешней скриптовой камере и отсутствию владельца
нашего `ControlSession`, не официальный API Menyoo. Старый `DanceMode.dll`
не удаляется автоматически: отключите его вручную, если он установлен, иначе
обе реализации могут реагировать на Y. Старые автосохранения не импортируются.
Сохранение анимаций в карты Menyoo пока не реализовано и не гарантируется.

Автотест чтения каталога, избранного, поиска и страниц:
`powershell.exe -NoProfile -ExecutionPolicy Bypass -File modules\Animations\tests\test-ped-animations.ps1`.
Игровые проверки: выбор через препятствие, повторный выбор, смена анимации во
время загрузки, удаление педа, ragdoll, возврат через Backspace, выход из Spooner,
остановка и F5 во время загрузки/проигрывания.

### Общие правила

1. Добавьте класс с публичным конструктором без параметров и `IGtaPlugin`.
2. В OnStart загрузите настройки, создайте меню и зарегистрируйте обработчики.
3. В OnTick обновляйте интерфейс и активную механику. Тяжёлые сканирования
   выполняйте по интервалу; не блокируйте поток ожиданием загрузки модели.
4. В OnKeyDown обрабатывайте клавишу меню. Проверьте занятые клавиши:
   `rg -n "Keys\." "modules\<ID>\src\Code"`.
5. В OnAbort освободите созданные сущности и камеру, восстановите изменённые
   параметры игрока и мира, сохраните настройки. Очистка должна выдерживать
   повторный вызов и частично завершённую инициализацию.
6. Выполните Check, затем Update и воспроизведите поведение в игре.

Не меняйте значения существующих enum в сохранениях без миграции.
Новым JSON-полям задавайте совместимые значения по умолчанию.
Не удаляйте чужие сущности и не сбрасывайте глобальную физику без учёта других модов.
Взаимодействие RemoveDroppedPeds, SharkRider и камеры требует отдельной игровой
проверки: успешная компиляция не подтверждает правильность поведения.

Перед завершением изменения проверяйте: включение/выключение, смерть или смену
персонажа, потерю целевой сущности, открытое меню, F5 во время активного эффекта
и повторный запуск. Для камеры дополнительно проверяйте старые пути, поворот
на 180 градусов, FOV и резкий возврат с последней ноды на первую.

## Диагностика и релизы

### Общий регистратор сбоев GTA V

`CrashPlugin.cs` автоматически запускает тихий `CrashWatcher.exe`. Наблюдатель
работает отдельно от процесса игры, поэтому после падения GTA может прочитать журнал
Windows, логи ScriptHookV/ScriptHookVDotNet, ASI-модов и Reloader. Никакие данные не
отправляются в интернет.

При обнаруженной проблеме создаётся файл:

```text
scripts\ReloaderPlugins\Plugins\Crash\Data\CrashReports\<дата-время>\CrashReport.txt
```

В начале отчёта указаны категория, код завершения и подтверждённые события Windows.
`Application Error`, сбойный модуль и код исключения являются фактами из Windows;
последние строки модовых логов показывают контекст и сами по себе не доказывают,
какой мод виноват. Если Windows не оставила свидетельств, причина честно отмечается
как неизвестная. Обычное закрытие с кодом 0 отчёт не создаёт. Зависание фиксируется,
если окно не отвечает не менее 60 секунд. Хранятся последние 20 отчётов.

Текущая история watcher находится в `scripts\ReloaderPlugins\Plugins\Crash\Data\CrashMonitor.log`.
В этой же папке хранятся временные файлы сессии и рабочая копия watcher.
Для передачи ошибки достаточно всей папки конкретного отчёта. Минидампы необязательны
и по умолчанию выключены. После распаковки архива в `Plugins` включите их
однократным запуском `Plugins/Crash/Tools/InstallCrashDumps.cmd` с подтверждением UAC. Разработчик
может использовать те же настройки через:

```powershell
.\modpack.cmd CrashDumps On
.\modpack.cmd CrashDumps Off
```

Первый вариант включает Windows Error Reporting только для `GTA5.exe` через
`HKLM`, сохраняет до трёх минидампов в
`scripts\ReloaderPlugins\Plugins\Crash\Data\CrashDumps`; второй отключает будущие
дампы, не удаляя уже созданные. Оба варианта требуют права администратора только
при изменении настройки и проверяют результат в реестре. Во время игры дамп
не записывается: Windows создаёт его после зарегистрированного сбоя. Принудительное
завершение GTA, зависание и собственный обработчик игры могут не создать `.dmp`.
Для таких случаев есть отдельный, по умолчанию выключенный режим `CrashCapture`.
Пользователь запускает `InstallCrashCapture.cmd` в папке `Plugins/Crash/Tools`, принимает
загрузку и лицензию Microsoft ProcDump; `DisableCrashCapture.cmd` отключает режим.
Разработчик может выполнить `modpack.cmd CrashCapture On|Off`. Инструмент не
входит в архив релиза: при включении скачивается с официального сайта Microsoft,
проверяется цифровая подпись, а затем CrashWatcher подключает его к PID GTA.
Триггеры: необработанное исключение, зависание окна и завершение процесса.
Обычное завершение тоже может дать диагностический дамп; оно помечается как
штатное, а не как краш. Последние три папки `CrashDumps\Capture-...` содержат
минидамп, `ProcDump.log`, PID/время и копию `CrashReport.txt`. Дампы могут
содержать чувствительные данные и никуда автоматически не отправляются.
При следующем реальном падении ищите также `CrashReport.txt`; дамп анализируется
отдельно, без автоматического WinDbg. Изолированная проверка watcher:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\modules\Crash\tests\test-crash-watcher.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\modules\Crash\tests\test-crash-capture.ps1 -Simulated
```

После принятия лицензии и установки ProcDump запустите
`modules\Crash\tests\test-crash-capture.ps1` без `-Simulated`: тестирует реальные триггеры
на отдельном процессе, не на GTA.

### Режим разработчика

`Ctrl+F10` открывает меню разработчика. «Режим разработчика» включает подробный
лог; «Показывать панель» отдельно выводит владельца управления, состояния камеры
и акулы и последние пять событий. Обе опции изначально выключены. Режим логирования
сохраняется, но панель всегда скрывается после запуска и F5. Если комбинация
используется сторонним модом, это не отслеживается автоматически.

Лог: `scripts/ReloaderPlugins/Development.log`. Одинаковые события допускаются
раз в три секунды; максимальный размер — 5 МБ, одна предыдущая копия хранится
в `Development.log.previous`. Панель обновляет текст пять раз в секунду.
Обычные ошибки плагинов записываются в прежние логи независимо от этого режима.

Для камеры ищите `Damage ped` (способ обнаружения), `Target already followed`,
`No fresh eligible damage target` и `Blocked by`. Для акулы отображаются состояния
Spawning, Approaching, Mounting, Riding, AttackAligning, BiteScene и события остановки.
После отклонённой автоматической посадки/укуса нужно выйти из воды или отойти от
акулы дальше шести метров и подойти заново. Отклонённый удар не ставится в очередь.

### Владение управлением

Камера и акула получают общий `ControlSession` до вмешательства в игрока.
Текущий эффект имеет приоритет; конфликтующий ручной запуск показывает причину,
автоматический отказ только логируется. Выходное затемнение камеры тоже занимает
управление. Обычные меню и механики NPC продолжают работать.

При завершении восстанавливается снимок заморозки, видимости, коллизии и неуязвимости
исходного персонажа. Для времени сохраняется фактический TimeScale; для изменённой
гравитации возвращается штатный preset 0, поскольку API не предоставляет надёжного
чтения предыдущего preset. Координация распространяется только на моды этого пака:
состояние Menyoo и других установленных модов автоматически не согласуется.
При смерти/смене персонажа эффект завершается; снимок не применяется к новому педу.

### Резервные сохранения

Пути камеры, настройки SharkRider, RemoveDroppedPeds, RainbowPaint и его исключения,
DevelopmentSettings и INI MenyooStreamer используют `SafeFiles`.
При повторной успешной записи предыдущая исправная версия сохраняется как `.bak`.
Запись идёт через временный файл и атомарную замену. Старые форматы не меняются.

Если основной файл повреждён, исправная `.bak` восстанавливается автоматически;
повреждённый оригинал остаётся под именем `.corrupt-<id>`. Если повреждены обе копии,
мод может использовать стандартные настройки в памяти, но сохранение поверх
повреждённых файлов блокируется проверкой содержимого. Восстановите валидный основной
файл вручную или явно удалите обе копии, если они больше не нужны. Затем повторите
сохранение. Не удаляйте файлы, если ещё рассчитываете восстановить данные.

Переименование пути сначала записывает новый файл и только после успеха удаляет старый.
Существующий путь назначения не перезаписывается. При удалении пути его резервная
копия также удаляется. XML-миграция не заменяет существующий JSON; успешно перенесённый
XML остаётся архивом `.xml.archived-<id>`. Архивы и повреждённые копии не показываются
в меню и могут быть убраны вручную после проверки данных.

Для проверки общих сервисов без игры:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\modules\Core\tests\test-modpack.ps1
```

Эти тесты используют имитацию GTA API для владения управлением и реальные временные
файлы для сохранений. Они не проверяют анимации, физику и затемнения в запущенной GTA.

- `Reloader.log`: компиляция, запуск, ошибки жизненного цикла и отпечаток.
- `compile_errors.txt`: ошибки и предупреждения компилятора с файлами и строками.
- `PluginErrors.log`: общий ограниченный по частоте лог некоторых плагинов.
- `CrashMonitor.log`: запуск watcher, зависания и создание crash-report.
- `CrashReports`: последние 20 текстовых отчётов о проблемных завершениях GTA.
- Остальные плагины могут вести собственные логи в ReloaderPlugins.

Обычный `dotnet build modules/Loader/src/Reloader.csproj` проверяет только
загрузчик. `modpack.cmd Check` также собирает CrashWatcher и проверяет плагины
живым CodeDOM-компилятором. `tools/build-loader.cmd`
сначала запускает Check, затем собирает загрузчик.

Перед релизом проверьте синхронность исходников и dist, игровые сценарии
и совместимость сохранений. Архив `ModPack-Plugins-X.Y.zip` содержит прямое
содержимое `dist/ReloaderPlugins/Plugins`, без родительской папки Plugins
и без Reloader.dll. Обновление загрузчика распространяйте отдельно с инструкцией
закрыть игру. Пользовательские JSON-настройки не включайте в обновление.
Релиз и отправка в GitHub не входят в Check/Update.
