GTA V ModPack
=============

Актуальные описания модов и клавиш: docs\MODS_RU.md. Подробности каждого
модуля находятся в modules\<ID>\README.md. Инструкции по релизу 1.6 ниже
сохранены как справка для этой версии и могут отличаться от текущей структуры.

Разработка модов: DEVELOPMENT_RU.md
Структура папок: STRUCTURE_RU.md. План переноса: ROADMAP_RU.md.
Массовая регистрация педов: dist\Tools\PedImporter\PedImporter.exe.
Конвертация педа в статичный проп: dist\Tools\PedToProp\PedToProp.exe.
Эта отдельная программа не меняет GTA; инструкция находится рядом с ней.
Инструкция находится рядом с программой в README.md. Перед первым импортом
используйте «Проверить редактор»; автоматизация AddonPeds требует проверки в игре.
Анимации педов: Y в Object Spooner (F9). Выбери педов через прицел, затем
назначь зацикленное действие из пресетов, полного каталога или избранного Menyoo.
При выходе из Spooner анимации продолжаются. В карты Menyoo они пока не сохраняются.
Старый DanceMode.dll нужно отключить, если он установлен: он тоже использует Y.
Проверить плагины: modpack.cmd Check
Проверить и обновить: modpack.cmd (сначала настройте modpack.local.json).

ModPack - набор скриптовых модов для GTA V на базе собственного загрузчика
Reloader. Загрузчик один (`Reloader.dll`), а сами моды лежат отдельными
файлами в папке `ReloaderPlugins\Plugins` и компилируются при запуске игры.

GitHub release 1.6:
  https://github.com/Wladisl4W/GTA-V_ModPack/releases/tag/v1.6

Для обновления уже установленного ModPack скачайте файл:

  ModPack-Plugins-1.6.zip

Из архива нужно взять все файлы и скопировать их с заменой в папку:

  GTA V\scripts\ReloaderPlugins\Plugins\

ВАЖНО: Чтобы CrashLogger собирал минидампы памяти после краша, одного
копирования архива недостаточно. После распаковки один раз запустите
`GTA V\scripts\ReloaderPlugins\Plugins\Crash\Tools\InstallCrashDumps.cmd` и подтвердите
запрос прав администратора. Дождитесь сообщения `GTA5 minidumps enabled`.
Установщик настроит Windows только для `GTA5.exe`. При каждом запуске игры
права администратора больше не запрашиваются, постоянной записи дампов нет.
После следующего зарегистрированного Windows краша файл `.dmp` появится в
`GTA V\scripts\ReloaderPlugins\Plugins\Crash\Data\CrashDumps`; текстовый отчёт ищите
в `Plugins\Crash\Data\CrashReports`. Принудительное завершение игры и некоторые
собственные обработчики сбоев могут не создать дамп. Без этого шага
CrashReport.txt всё равно создаётся, но дампа памяти не будет.

Для случаев, когда GTA зависает или просто закрывается без записи WER,
используйте `InstallSilentExit.cmd` из папки `Plugins\Crash\Tools`. Он однократно запросит
права администратора и включит системный захват тихого завершения GTA5.exe
без постоянного отладчика. `DisableSilentExit.cmd` восстановит прежние
настройки реестра; дампы останутся. Снимок может появиться и при обычном
выходе, но отчёт не объявит такой выход крашем. При зависании дольше минуты
CrashWatcher попытается снять один отдельный минидамп. Системный механизм
не охватывает все способы завершения и не гарантирует установление виновного
мода.

Старый режим CrashCapture подключает ProcDump к каждой сессии и на некоторых
системах мешает запуску GTA. Он по умолчанию выключен; для эксперимента
доступен дополнительный режим CrashCapture. Один раз запустите из папки
`Plugins\Crash\Tools` файл `InstallCrashCapture.cmd`, подтвердите загрузку официального
Microsoft ProcDump и его лицензию. После этого CrashLogger автоматически
подключает ProcDump к каждой новой игровой сессии. Отключение:
`DisableCrashCapture.cmd` из той же папки. Дампы и вывод инструмента ищите
в `Plugins\Crash\Data\CrashDumps\Capture-...`. Хранятся последние три сессии.
Даже минидамп может содержать личные данные из памяти игры; не публикуйте
его открыто. При обычном выходе тоже может быть записан дамп завершения.
Эти установщики добавлены после релиза 1.6 и появятся в следующем архиве.

Важно:
  • архив релиза содержит именно содержимое папки `Plugins`;
  • распаковывать его нужно в `ReloaderPlugins\Plugins`, не в корень GTA V;
  • `Reloader.dll` в этот архив не входит, потому что он нужен только для
    полной установки или отдельного обновления загрузчика.

Если у вас загрузчик старше версии 2.0, установите его один раз из
`Reloader-2.1.zip`: закройте GTA V и замените `GTA V\scripts\Reloader.dll`.
Загрузчик 2.1 дополнительно записывает подробные ошибки плагинов, но для
самого CrashLogger достаточно уже установленной версии 2.0.

Требования:
  • Script Hook V        — http://www.dev-c.com/gtav/scripthookv/
  • Script Hook V .NET 3 — https://github.com/scripthookvdotnet/scripthookvdotnet-nightly/releases
  • LemonUI              — https://github.com/LemonUIbyLemon/LemonUI

Установка:
  Если используете GitHub-релиз, распакуйте ModPack-Plugins-*.zip в
  `GTA V\scripts\ReloaderPlugins\Plugins`, сохраняя вложенные папки.
  Архив Reloader-*.zip устанавливается отдельно. При локальной сборке те же
  файлы находятся в `dist`.
  1. Установите Script Hook V и Script Hook V .NET в корень GTA V.
     LemonUI.SHVDN3.dll должен лежать в:

       GTA V\scripts\

  2. Если загрузчик ещё не установлен, скопируйте `Reloader.dll` из `dist`
     либо архива Reloader-*.zip в:

       GTA V\scripts\

  3. При локальной сборке скопируйте папку `ReloaderPlugins` из `dist` в:

       GTA V\scripts\

  4. По желанию один раз запустите
     `GTA V\scripts\ReloaderPlugins\Plugins\Crash\Tools\InstallCrashDumps.cmd` и
     подтвердите запрос администратора для записи минидампов Windows.
     Для расширенной диагностики закрытий и зависаний отдельно запустите
     `InstallCrashCapture.cmd` из той же папки.

  5. Запустите игру. Плагины скомпилируются автоматически.

После установки структура должна выглядеть так:

  GTA V\scripts\Reloader.dll
  GTA V\scripts\ReloaderPlugins\Plugins\<модуль>\Code\*.cs
  GTA V\scripts\ReloaderPlugins\Plugins\Crash\Tools\CrashWatcher.exe
  GTA V\scripts\ReloaderPlugins\Plugins\Newtonsoft.Json.dll

  Newtonsoft.Json.dll — единственный файл в корне Plugins. Это общая
  библиотека модпака для камеры; её расположение сохранено намеренно.

  МОДЫ И ГОРЯЧИЕ КЛАВИШИ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  • Справочник модов (F5)
    Показать список модов. Reloader автоматически перезагружает изменённые исходники.

  • Cinematic Moment (удерживать Mouse4)
    Замедлить время вдвое и включить плавную камеру для съёмки движения.
    Пока кнопка зажата, мышь меняет ракурс вокруг персонажа или машины.
    Отпускание кнопки плавно возвращает обычную камеру и сразу восстанавливает
    скорость времени.

  • Spooner Prefabs (; / :)
    В Object Spooner: выбрать стенку 10×5 из stunt soccer balls, навести
    предпросмотр и нажать Enter или ; для размещения. После создания мячи
    становятся динамическими. Backspace отменяет предпросмотр.
    Размещённые объекты можно сохранить через Save World в Menyoo.

  • Modded Camera (T)
    Кинематографическая камера и пролёты по точкам.
    Backspace - назад/выход из текущего меню.

    Особенности:
      - сохранение и загрузка путей камеры;
      - индивидуальная длительность, FOV, цвет и режим интерполяции для нод;
      - режимы интерполяции: Linear, SmoothStop, SmoothNoStop;
      - совместимость со старыми сохранёнными путями;
      - меню настроек камеры не меняет общий FOV, FOV настраивается через ноды;
      - зацикливание пролётки: последняя нода держится по своей длительности,
        затем происходит резкий переход к первой ноде;
      - отдельный режим "Следование камеры": камера может следовать за педом
        после нанесения урона, с настраиваемой длительностью, гравитацией
        и силой удара.

  • Rainbow Paint (I)
    Радужная покраска машин.
    Выделение машины работает в Object Spooner (Menyoo): включите его,
    наведите камеру на машину и нажмите I.
    В рандомайзере можно выбрать участвующие цвета, включить дым шин в цвет
    основного цвета и задать кастомный номер для машин в мире.

  • Remove Dropped Peds (H)
    Удаление педов, упавших в воду, включая мёртвых.

  • MenyooStreamer (U)
    Стриминг педов из Menyoo.
    Радиусы стриминга считаются по горизонтали без учёта высоты, область
    работает как цилиндр.

  • Frozen Dynamic (K)
    Заморозка/разморозка всех NPC. Танцы сохраняются.

  • Shark Rider
    Автономный мод: в воде рядом спавнится акула и подплывает к игроку.
    WASD - плыть, Shift - всплыть, Ctrl - погрузиться. Выход на сушу
    отпускает акулу.
    В меню O отдельная галочка «Крокодил»: при нахождении в воде рядом
    с берегом один a_c_crocodile появляется на суше и преследует игрока.
    Крокодил продолжает погоню на суше и работает независимо от акулы.
    Скрипт не наносит урон сам, но штатный боевой ИИ может укусить.
    Если в игровых scripts установлен старый Crocodile.dll, отключите его,
    иначе два скрипта будут создавать крокодилов одновременно.

  • scripts\ReloaderPlugins\Plugins\Crash\Data\CrashReports\<дата-время>\CrashReport.txt

    код завершения, установленные моды и последние строки полезных логов.

  • scripts\ReloaderPlugins\Plugins\Crash\Data\CrashMonitor.log
    История работы фонового регистратора. Данные никуда не отправляются.

  • scripts\ReloaderPlugins\Plugins\Crash\Data\CrashDumps\Capture-...\
    Минидамп, вывод ProcDump и копия отчёта при включённом CrashCapture.

  • scripts\ReloaderPlugins\Plugins\Camera\Data\Saves\Paths\
    Сохранённые пролёты Modded Camera.

  • scripts\ReloaderPlugins\Menyoostreamer.ini
    Настройки MenyooStreamer.

  • scripts\ReloaderPlugins\RainbowPaintSettings.json
    Настройки Rainbow Paint: цвета рандомайзера, дым шин и кастомный номер.

Исходники лежат в папке:

  modules

Структура:
  • modules\Loader\src\ — проект загрузчика (.NET Framework 4.8)
  • modules\<модуль>\src\Code\ — исходники игровых плагинов (*.cs)
  • modules\Crash\src\ — внешний регистратор завершения GTA
  • tools\build-loader.cmd — сборка Reloader.dll

Сборка:

  modpack.cmd Check
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools\package-release.ps1

Во время разработки можно менять файлы плагинов в:

  GTA V\scripts\ReloaderPlugins\Plugins\

Reloader заметит изменения и автоматически перекомпилирует плагины.
