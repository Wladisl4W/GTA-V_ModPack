# Установка и обновление ModPack

Текущий релиз содержит основной архив `ModPack-Install-2.0.0.zip` для установки и обновления, а также четыре отдельных ZIP для ручной установки плагинов, загрузчика и двух программ. Историческая инструкция релиза 1.6 находится в `docs/history/README_1.6.txt` и для нынешней структуры не подходит.

## Перед установкой

Закройте GTA. Нужны GTA V, Script Hook V, ScriptHookVDotNet3 и LemonUI.SHVDN3. Сделайте резервную копию `GTA V/scripts/Reloader.dll` и `GTA V/scripts/ReloaderPlugins/Plugins`, если они уже существуют. Сохраните также отдельную копию пользовательских данных `Plugins/<модуль>/Data` и старых папок данных в `ReloaderPlugins`, если обновляете прежнюю версию.

## Рекомендуемая установка и обновление

Скачайте `ModPack-Install-2.0.0.zip`, распакуйте в отдельную временную папку и при закрытой GTA выполните:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\Install-ModPack.ps1" -GameDirectory "C:\Program Files (x86)\Steam\steamapps\common\Grand Theft Auto V"
```

Установщик проверяет содержимое архива по SHA-256, сохраняет заменяемые файлы и известные старые плоские файлы ModPack в `%LOCALAPPDATA%/ModPack/UpgradeBackups`, затем устанавливает загрузчик и плагины. Пользовательские настройки, карты Menyoo и архивы AddonPeds он не меняет. Неизвестные `.cs` в корне `Plugins` вызывают остановку **до копирования**. Для отката используйте сохранённые файлы из указанной папки; данные предварительно скопируйте отдельно. Подробности перехода с версии 1.6: [заметки релиза](releases/v2.0.0.md).

## Ручная чистая установка

1. Из `Reloader-<версия>.zip` скопируйте `Reloader.dll` в `GTA V/scripts`.
2. Содержимое `ModPack-Plugins-<версия>.zip` распакуйте в `GTA V/scripts/ReloaderPlugins/Plugins`. Внутри должны появиться каталоги модулей `Core/Code`, `Camera/Code` и другие, папка `Crash/Tools`, а в корне `Plugins` — `Newtonsoft.Json.dll`.
3. `PedImporter-<версия>.zip` и `PedToProp-<версия>.zip` распакуйте в отдельные удобные папки, только если нужны эти программы. Они не являются игровыми плагинами.
4. Запустите GTA. Откройте F5 — каталог модов. Проверка для разработчика: в `scripts/ReloaderPlugins/Plugins/Loader/Data/Logs/Reloader.log` должны появиться `Loaded 13 plugin(s)` и свежая строка `Reload OK`.

## Ручное обновление с прежней структуры

1. Рекомендуется использовать основной архив с установщиком выше. При ручном обновлении закройте GTA и сохраните резервные копии, как указано выше. Архив плагинов содержит **только поставляемые файлы**; простая распаковка поверх старой плоской папки не удаляет устаревшие `.cs`, и загрузчик может увидеть оба набора.
2. Если вы работаете из исходного проекта, задайте путь GTA в `modpack.local.json`, выполните `modpack.cmd Check`, затем `modpack.cmd Update -Offline`. Эта команда проверяет старые исходники, переносит известные плоские копии и сверяет SHA-256. При неизвестных `.cs` она останавливается и сообщает имена для ручного разбора.
3. Если обновляете только из ZIP, после резервного копирования сравните старые `.cs` в корне `Plugins` со списком прежнего релиза. Уберите **только проверенные устаревшие исходники ModPack** из корня, затем распакуйте новый архив. Чужие `.cs`, пользовательские данные и резервные копии оставьте. При сомнении используйте путь обновления через исходный проект из пункта 2.
4. `Reloader.dll` заменяйте отдельно при закрытой GTA. Пользовательские `Data` не очищайте: `PluginStorage` перенесёт известные прежние настройки при первом обращении. Различающиеся файлы будут сохранены в `Data/Legacy`.
5. После запуска проверьте свежие строки журнала и сохранённые настройки. Для отката закройте GTA, верните резервную копию исходников и соответствующий ей `Reloader.dll`; текущие данные сначала скопируйте отдельно.

Menyoo, AddonPeds, игровые архивы и содержимое `assets/models` этими архивами не устанавливаются. Подробности о данных и командах: [реестр доставки](DATA_AND_DELIVERY_RU.md) и [руководство разработчика](DEVELOPMENT_RU.md).
