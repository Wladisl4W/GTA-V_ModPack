# Шаблон README модуля

Копировать содержание в подробное описание `docs/modules/<ID>.md`. Краткий README игрового меню хранится рядом с его кодом в `scripts`; профильные тесты — в `development/tests/<ID>`. Удалять подсказки в угловых скобках после заполнения. Точный технический ID, клавишу и список `.cs` сверять с [`development/registry/modules.json`](../development/registry/modules.json), пользовательские действия — с кодом и игрой. Пример не является готовым описанием Camera, Paint или Wildlife.

```markdown
# <Русское название> (<ID>)

<Одно-два предложения: что получает игрок и где это применяется.>

## Как запустить

<Клавиша, требуемый режим GTA/Object Spooner, условия открытия меню. Если клавиши нет — как запускается инструмент или служба.>

## Что можно сделать

- <Основное действие и результат.>
- <Другие значимые действия. Для сложного модуля — подразделы по функциям.>

## Данные

<Точные файлы настроек, сохранений и журналов относительно scripts/ReloaderPlugins; что сохраняется после перезапуска. Если файлов нет — «Нет постоянных данных».>

## Зависимости и ограничения

<Reloader/ScriptHookVDotNet/LemonUI, необходимые модели или внешние файлы. Указать ограничения, которые влияют на использование; Menyoo и AddonPeds обозначать как внешние зависимости. Если внешних зависимостей нет — так и написать.>

## Исходники

<Каноническая папка кода и 1–3 главных файла или ссылка на development/registry/modules.json для длинного списка. Где находится локальная поставка.>

## Проверка

<Команда сборки и профильные тесты. Что уже проверено в GTA, а что ещё не проверено. Не выдавать успешную компиляцию за игровую проверку.>

## Обновление и откат

<Какие данные сохранить перед изменением, как доставляется модуль и как вернуть предыдущую проверенную версию. Для служебного модуля указать его особый порядок.>
```

## Проверка применимости

| Модуль | Что шаблон должен вместить без исключений |
| --- | --- |
| Camera | Пролётки и пути, T, сохранения `Data/Saves/Paths`, журнал, проверка переходов и игрового ракурса. |
| Paint | Покраска, обмен моделей и пассажиры в одном меню I; четыре файла настроек; отдельная проверка результата в GTA. |
| Wildlife | Акула и крокодил, O, сохранение галочек, журнал, зависимость от установленной модели крокодила. |
| Weapons | Одна клавиша L, простой список действий, отсутствие собственных постоянных данных. |

Этот список проверяет полноту **шаблона**. Содержательные README модулей доступны через [общий указатель](MODS_RU.md).
