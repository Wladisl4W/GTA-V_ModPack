# Разработка (Dev)

Служебное меню включает диагностику модпака и экранную панель состояний.

## Как запустить

Нажмите **Ctrl+F10** в GTA. В меню включите «Режим разработчика», затем при необходимости «Показывать панель».

## Что можно сделать

- Видеть диагностические состояния и владельца общего управления на экране.
- Записывать события модулей для разбора ошибок. Отключение режима скрывает панель.

## Данные

Галочка режима сохраняется в `scripts/ReloaderPlugins/Plugins/Dev/Data/Settings/DevelopmentSettings.json`, события — в `Data/Logs/Development.log`. Старые имена файлов сохранены для совместимости.

## Зависимости и ограничения

Нужны Reloader, ScriptHookVDotNet3 и LemonUI. Панель предназначена для разработки; она не исправляет игровые сбои сама по себе.

## Исходники и проверка

Код: [DevPlugin.cs](../../scripts/ReloaderPlugins/Plugins/_System/Diagnostics/Code/Dev/DevPlugin.cs), общий диагностический буфер — в Core. Выполните `modpack.cmd Check`, затем проверьте в GTA включение, выключение и повторный запуск.

## Обновление и откат

`modpack.cmd Update Dev` доставляет исходник. Для отката сохраните JSON и восстановите проверенную копию.
