# Финальная проверка перестройки ModPack

Снимок проверки от 21 ноября 2026 года перед выпуском 2.0.0. Текущий порядок обновления со старой версии описан в [заметках релиза](releases/v2.0.0.md).

| Данные и ресурсы | 8 исторических ключей хранения, 18 обращений; 14 локальных файлов модели сверены по SHA-256 и отсутствуют в ZIP |

| Чистая поставка и обновление | `tools/package-release.ps1` распаковал и сверил пять архивов; `tools/test-update.ps1` и `tools/test-install-release.ps1` проверили старую плоскую структуру, выборочное обновление, резервную копию и хеши на временной копии |

Тест захвата дампов выполнялся в симулированном режиме. Естественный сбой GTA, визуальный результат камеры, животных и других игровых действий этими тестами не подтверждаются.

## Игровая проверка и ограничения

Пользователь проверил игру после перестройки и сообщил, что всё работает. Журнал этого запуска подтвердил загрузку всех 13 плагинов, а повторная сверка показала совпадение 46 файлов поставки с GTA. Это подтверждает общую работоспособность структуры и загрузки; отдельные сценарии выбора педов и анимаций, покраски, обмена машин, генератора горки, акулы, крокодила и двух самостоятельных программ в рамках финального этапа заново не проходились. Отчёт CrashWatcher при естественном сбое проверять только если такой сбой действительно возникнет.

## Состав будущего Git-изменения

- Внести `modules`, `catalog`, `docs`, `tools`, текущие корневые инструкции, `.agents/skills/gta-modpack` и обновлённый workflow. Сопоставить удаления старых `Source Code`, `Ready To Use` и старых путей тестов с новыми модулями по `catalog/modules.json` и `catalog/source-renames.json`.
- **Обязательно включить** `modules/Core/assets/Newtonsoft.Json.dll`: сборка берёт этот файл из нового пути, его SHA-256 совпадает с прежним отслеживаемым `Ready To Use/ReloaderPlugins/Plugins/Newtonsoft.Json.dll`. GitHub Actions строит `Reloader.dll` из исходников, поэтому локальная справочная копия в `modules/Loader/assets` не нужна в коммите.
- Не включать `dist`, `.modpack-local`, `modpack.local.json`, `ScriptHookV.log`, `assets/models`, пользовательские `Data`, дампы и резервные копии. Модели исключены из Git из-за неподтверждённых прав; сведения о них остаются в [реестре](ASSETS_RU.md). Проверить `git status --short --untracked-files=all` перед созданием коммита.
- `docs/history/README_1.6.txt`, `docs/INVENTORY_RU.md`, `docs/NAMING_MAP_RU.md` и `docs/history/release-notes-v1.5.md` сохранены как исторические страницы. Актуальная установка: [инструкция](INSTALL_RU.md). Workflow больше не ссылается на релиз 1.5 и публикует пять проверенных ZIP по будущему тегу.

## Проверка для трёх читателей

- **Игрок:** из корневого README открыть [установку](INSTALL_RU.md) и [список модов с клавишами](MODS_RU.md), затем README нужного модуля.
- **Новый разработчик:** из [структуры](STRUCTURE_RU.md) найти ID в `catalog/modules.json`, перейти к `modules/<ID>/README.md`, `src` и `tests`.
- **Автор изменений:** из [руководства](DEVELOPMENT_RU.md) перейти к [данным и доставке](DATA_AND_DELIVERY_RU.md), проверить модуль и пакет до работы с установленной игрой.

Структурная перестройка проверена. Подробная визуальная проверка функций остаётся задачей соответствующих модулей при их следующих изменениях.
