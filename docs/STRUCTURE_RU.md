# Структура ModPack

Очередность оставшихся работ и критерии завершения: `ROADMAP_RU.md`.

## Корень проекта

Корневой [README](../README.md) — начальная точка для игрока и разработчика. `modules` содержит код и README модов, `docs` — инструкции и историю, `tools` — команды, `catalog` — реестр, `assets` — рабочие ресурсы. `dist` и `.modpack-local` создаются локально и не входят в Git. Корневые `modpack.cmd` и `modpack.example.json` нужны для запуска и настройки; `modpack.local.json` — личный конфиг, который читают команды проекта. Скрытые папки `.git`, `.github`, `.agents`, `.codex` остаются в корне из-за соглашений соответствующих инструментов.

## Найти нужный мод

Выполните `modpack.cmd Map`, затем откройте `.modpack-local/project-map.html`. Поиск принимает название мода, клавишу и имя исходного файла. Карта показывает исходники, README и наличие файлов в установленной игре. Это локальный снимок; обновляйте его той же командой. HTML и сведения о локальной установке игнорируются Git.

Источник сведений о модулях — `catalog/modules.json`. Каждый модуль описан в `modules/<имя>/README.md`. Если новый исходник не внесён в реестр или один файл записан за двумя модулями, команда проверки завершится ошибкой.

Правила именования и написания кода: `docs/CONVENTIONS_RU.md`. При заполнении нового README используйте `docs/MODULE_TEMPLATE_RU.md`; сгенерированная карта создаёт только начальную страницу.
Владельцы игровых данных и порядок доставки описаны в [реестре данных и доставки](DATA_AND_DELIVERY_RU.md), модели и изображения — в [реестре ресурсов](ASSETS_RU.md).

## Состояние переноса

На этапе 3 единый корень исходников, README и профильных тестов — `modules/<ID>`. Общие команды и тесты поставки находятся в `tools`, локальные модели — в `assets/models`, исторический анализ — в `docs/history`. `dist` создаётся командами сборки и игнорируется Git. `tools/package-release.ps1` собирает пять ZIP архивов и сверяет содержимое после распаковки. GitHub Actions собирает загрузчик из исходников; игровая DLL обновляется отдельно командой установки и не копируется командой `Update`. Модели с неподтверждёнными правами остаются локальными и исключены из Git.

Предыдущая локальная поставка и оставшиеся каталоги старой разработки сохранены в `.modpack-local/backups/stage3-20261120-214139`; архив не публикуется. Все 35 исходников и 14 файлов моделей сверены при переносе. После доставки этапа 3 совпали все 46 файлов локальной поставки и GTA; обновился только `CrashWatcher.exe`. Запуск GTA 21 ноября подтвердил загрузку 13 плагинов и ожидаемый отпечаток исходников. `Reloader.dll` в игре не заменялся.

Все игровые исходники находятся в `modules/<модуль>/src/Code`. Локально собираемые и игровые копии находятся в таких же подпапках `ReloaderPlugins/Plugins/<модуль>/Code`; хеши всех 35 файлов сверены. Загрузчик следит за подпапками и всё ещё умеет читать старую плоскую папку для переходных установок. Обычные настройки, журналы и пути камеры находятся в `ReloaderPlugins/Plugins/<модуль>/Data`.

Единственный файл непосредственно в корне `ReloaderPlugins/Plugins` — общая `Newtonsoft.Json.dll`. За её поставку отвечает Core; камера использует библиотеку для сохранения путей. Она остаётся в корне как доступная загрузчику общая зависимость. Копия в `scripts` находится вне этой структуры и не изменяется.

Загрузчик, проверка и доставка поддерживают смешанную структуру. При переносе модуля `Update` сначала копирует файл в новую папку и проверяет SHA-256, затем удаляет старую копию; при ошибке в ходе доставки восстанавливает предыдущие байты. Проверенные копии прежних этапов — в `.modpack-local/backups/structure-20261119-233027`, `data-20261119-234745`, `crash-20261119-235939`, `loader-20261120-195325`, `crash-tools-20261120-201042`. Запуски GTA до и после этапа 3 подтвердили загрузку 13 плагинов; после переноса журнал Reloader содержит ожидаемый отпечаток исходников. Системные пути дампов перенесены и сверены в реестре. Menyoo и AddonPeds не переносились. Собственные файлы из `MODELS` находятся в `assets/models`.

## Добавить модуль

1. Добавьте запись с уникальным `id` в `catalog/modules.json` и перечислите все принадлежащие ему `.cs`.
2. Запустите `tools/build-project-map.ps1`. Она создаст начальный README нового модуля и обновит локальную карту. Существующий README не перезаписывается; заполните новый по `docs/MODULE_TEMPLATE_RU.md`.
3. Запустите `tools/build-project-map.ps1 -Check` и `modpack.cmd Check`.

Не публикуйте `.modpack-local` и не используйте файл карты как замену проверке в игре.
