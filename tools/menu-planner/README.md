# Интерактивная карта игровых меню

Откройте `index.html` двойным щелчком. Страница работает локально, без интернета и без запущенной GTA.

1. На первом экране показаны все клавиши. Нажмите на карточку, чтобы открыть главное меню соответствующего мода. Цвет карточки можно изменить через `✎`.
2. Строки с `›` открывают подменю; `☐` обозначает галочку, `◀` — список значений, `●` — действие. Нажатие в карте лишь показывает поведение, **ничего не применяя в игре**. Цвет текста каждого пункта можно настроить отдельно.
3. Чтобы переименовать, поменять тип, цвет, порядок или расположение пункта, нажмите `⋯ Переместить / изменить` справа от него. Там же выбирается новое меню и цель перехода. При переносе пункта с подменю само подменю переходит к той же клавише.
4. Можно добавлять клавиши, меню и пункты. Клавиша с пометкой «Пока не решил» подходит для ещё не выбранных функций. Пустую клавишу или пустое меню можно удалить через редактор.
5. Заметки к общему плану находятся под открытым меню. Сохранение в браузере автоматическое. Когда работа закончена, скачайте `modpack-menu-plan.json` и прикрепите его к сообщению. Файл можно снова открыть кнопкой «Открыть план». Читаемая Markdown-карта предназначена для просмотра.

Старая раскладка, сохранённая в предыдущей версии страницы, переносится автоматически. Её копия остаётся в локальном хранилище браузера под именем `modpack-menu-planner-v1-backup`. Ранее скачанный JSON также можно импортировать. Динамические игровые списки (сохранённые пути, пресеты, педы, цвета) представлены шаблонами.

Это макет. Он не меняет исходники, плагины, GTA, Menyoo или AddonPeds. Для разработки у каждого пункта сохраняется исходный модуль и старое расположение.
