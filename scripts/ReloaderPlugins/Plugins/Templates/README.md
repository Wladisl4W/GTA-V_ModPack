# Пресеты

Клавиша: **T**. Сохранённые сценарии массовых действий с машинами, педами, текстурами, погодой, облаками и заготовками.

В редакторе пресета включите «Спавнить префабы» и откройте «Задать префабы». Кнопка «Поставить новый» открывает выбор стенки мячиков или горки в Object Spooner (F9); Enter сохраняет место без создания объектов. Список хранит заготовки в порядке добавления, удаление каждого пункта требует подтверждения. При применении пресета прежний стриминг префабов заменяется новым. Горка сохраняет форму при отъезде и возвращении, но повторное применение пресета создаёт новую форму. Стриминг можно остановить в меню **O → Стриминг префабов**. Пресеты сохраняются в JSON, старые записи без заготовок продолжают загружаться.

Исходники Reloader компилирует из папки Code. Настройки и списки: Data/Settings.

Проверка сборки: `modpack.cmd Check` в каталоге разработки. Работу меню и игровых эффектов проверяйте в GTA.
