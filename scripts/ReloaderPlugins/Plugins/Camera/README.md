# Камера

Клавиша: **K**. Пролётки, узлы, сохранённые пути и случайное смешивание путей.

Во время замедленной пролётки камера автоматически подстраивает поворот по всем трём осям у замороженных пропов рядом с ней. Файлы Menyoo не меняются. Коррекция рассчитана на небольшие повторяющиеся относительные повороты; при ручном перемещении или резком изменении угла объект не корректируется.

Исходники Reloader компилирует из папки Code. Пролётки: Data/Paths. Старые сохранения переносятся с проверкой; не удаляйте прежние файлы до проверки в игре.

Проверка сборки: `modpack.cmd Check` в каталоге разработки. Работу меню и игровых эффектов проверяйте в GTA.
