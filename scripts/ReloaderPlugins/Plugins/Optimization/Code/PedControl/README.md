# Заморозка/Разморозка

Вход: O → Оптимизация → Заморозка/Разморозка. Команды сразу меняют состояние всех загруженных NPC, кроме игрока и прикреплённых педов; данные: ../../Data/PedControl.

Это самостоятельный раздел кода внутри меню Optimization. Исходники компилируются загрузчиком Reloader вместе с остальными плагинами.
