# Животные

Вход: L → Разное → Животные; Mouse5. Два переключателя акулы: «Кататься на акуле» и «Акула кусает». Включение одного выключает другой; оба можно выключить. Настройки прежнего режима автоматически читаются из SharkRiderSettings.json. При каждом создании акулы в обоих режимах случайно выбирается одна из трёх текстур тигровой акулы (0/1/2), как у Tiger Shark 1/2/3 в примере. Повторы допустимы; существующая акула сохраняет внешний вид до удаления. Если заменённая модель содержит меньше текстур, выбор ограничивается доступными. Крокодил управляется отдельно. Настройки и журнал: ../../Data/Wildlife.

При катании W/S задают ход, A/D поворачивают (D вправо), Shift наклоняет акулу и ведёт вниз, Ctrl наклоняет и ведёт вверх до поверхности воды, E позволяет слезть. Курс сохраняется после отпускания A/D. На время катания обычная камера третьего лица отдаляется; после слезания GTA возвращает обычную дистанцию. Режим укуса повторяет последовательность Maneater для живой жертвы: захват, удержание, 2–4 жевательных движения и отдельное движение освобождения. Случайно выбирается одно из трёх положений тела в пасти (middle/upper/lower). При захвате персонаж прикрепляется к кости головы по числовому индексу, во время укуса меняется его анимация, затем он освобождается в ragdoll. Скриптового урона нет. Запуск клипов передаёт начальные фазы из Maneater непосредственно в TASK_PLAY_ANIM. После исправления запуска полный цикл, положения тела и повторный укус требуют проверки в GTA.

Исследован пример `development/assets/sharkModExample`: пакет Maneater содержит обфусцированный `Maneater.ndll`, конфигурацию с `moveAnimSet=creatures@shark@move` и `attackAnimSet=creatures@shark@melee@streamed_core@`. После восстановления управляемого кода подтверждены клип `attack`, захват жертвы у кости головы с числовым ID 31086, анимации жертвы `dead@fall/dead_fall_up` и `missexile3_rpg/aim_breathe_additive`. Исходный мод останавливает первый клип после захвата, затем отдельным этапом запускает следующий укус и повторяет фрагмент клипа; `attack_jump` используется для атаки с выпрыгиванием. Бинарник Maneater не устанавливается. WAV-файлы из предоставленного примера находятся в `Misc/Assets/Wildlife/Sounds`: движение, укус и освобождение звучат на соответствующих этапах, с отдельными вариантами под водой. Воспроизведение через System.Media.SoundPlayer асинхронное, без сторонних DLL и пространственного позиционирования. Отход после укуса тормозит перед фиксированной точкой, останавливается в радиусе 0,6 м и сохраняет направление до следующего захода.

Это самостоятельный раздел кода внутри меню Misc. Исходники компилируются загрузчиком Reloader вместе с остальными плагинами.
