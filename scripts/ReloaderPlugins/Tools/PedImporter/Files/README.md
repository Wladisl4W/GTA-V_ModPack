# Ped Importer

Запускайте `PedImporter.cmd` из папки инструмента. В простом режиме выберите папку моделей, папку GTA и проверенных педов, затем добавьте их в избранное Menyoo. Файлы моделей и регистрация в AddonPeds должны быть готовы отдельно. Перед записью программа создаёт резервную копию XML.

Режим полного импорта использует AddonPeds Editor и требует отдельной подготовки. При ошибке сохраните журнал и исходный XML для разбора.
