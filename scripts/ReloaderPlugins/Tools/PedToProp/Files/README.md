# PedToProp

Запускайте `PedToProp.cmd` из папки инструмента. Выберите ровно четыре файла одного не-streamed педа (`.ydd`, `.ytd`, `.yft`, `.ymt`) и папку результата. Blender с Sollumz должен быть установлен и настроен через кнопку «Настроить конвертер» (служебный `Runtime/setup.ps1` запускается программой).

Программа не устанавливает результат в GTA. Проверьте созданный `.ydr` в просмотрщике перед размещением в игре.
